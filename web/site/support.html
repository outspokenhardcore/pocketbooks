Support

Help with the PocketBooks iPhone and iPad app.

Fastest way to get help: open an issue on GitHub, or write to henning@mauli.app.

I just want to try it

Open Settings in the app and tap Try the demo library. It plays five pre-generated public-domain books and needs no server and no token.

The app cannot connect to my server

  • Check that the server is running: the Mac must be awake and python -m app.serve must be active.
  • Enter the address with the port, for example http://192.168.1.10:8725.
  • Use the API token the server printed when it started. It is not your Apple ID password.
  • iPhone and Mac must be on the same network, or both on your Tailscale network.
  • If iOS asks to allow access to the local network, choose Allow. You can change this later in the iOS Settings under PocketBooks.

Playback starts but stops or stutters

While a book is still being generated you can only seek within the part that already exists. If the server is busy with another book, playback can pause until the next segments are ready. Generation is usually many times faster than listening.

Which books can I use?

Any PDF with a real text layer. Scanned, image-only PDFs are not supported. Only use books you are allowed to process.

Setting up the server

The full guide, including prompts for AI coding assistants, is in the repository.

Reporting a problem

Please say which device and iOS version you use, what you did, and what you expected. Do not send private books, tokens or server addresses.

Support

Hilfe zur PocketBooks-App für iPhone und iPad.

Am schnellsten: Eröffne ein Issue auf GitHub oder schreib an henning@mauli.app.

Ich will es nur ausprobieren

Öffne in der App die Einstellungen und tippe auf Try the demo library. Sie spielt fünf vorab erzeugte, gemeinfreie Bücher und braucht weder Server noch Token.

Die App erreicht meinen Server nicht

  • Prüfe, ob der Server läuft: Der Mac muss wach sein und python -m app.serve aktiv.
  • Gib die Adresse mit Port ein, zum Beispiel http://192.168.1.10:8725.
  • Nimm das API-Token, das der Server beim Start ausgegeben hat. Es ist nicht dein Apple-ID-Passwort.
  • iPhone und Mac müssen im selben Netz sein oder beide in deinem Tailscale-Netz.
  • Fragt iOS nach dem Zugriff auf das lokale Netzwerk, wähle Erlauben. Du kannst das später in den iOS-Einstellungen unter PocketBooks ändern.

Die Wiedergabe stockt oder bricht ab

Solange ein Buch noch erzeugt wird, kannst du nur in dem Teil spulen, der schon existiert. Ist der Server mit einem anderen Buch beschäftigt, kann die Wiedergabe pausieren, bis die nächsten Segmente fertig sind. Die Erzeugung ist meist um ein Vielfaches schneller als das Hören.

Welche Bücher kann ich nutzen?

Jedes PDF mit echter Textebene. Eingescannte PDFs nur mit Bildern werden nicht unterstützt. Nutze nur Bücher, die du verarbeiten darfst.
